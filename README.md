# linqwq

> 为 Android 重新设计的自由窗口桌面环境

## 这是什么

一个跑在 Android 上的桌面环境。不是把 Linux 桌面塞进平板，而是从头设计一套适合触屏的窗口管理与交互系统。

## 要解决什么

Android 的多窗口能力是残缺的——分屏最多两个，窗口不能自由摆放，更谈不上层级和吸附。PC 桌面之所以好用，核心在于自由窗口；但那套交互建立在键盘快捷键上，直接搬到触屏就废了。

linqwq 想做的是：**把自由窗口还给 Android，并用触摸重新定义它。**

## 核心思路

1. **自由窗口** —— 每个应用都是可拖动、可缩放、可吸附的窗口
2. **手势优先** —— 不移植键盘快捷键，而是重新设计手势词表（指头数、方向、速度、组合）
3. **渲染自主** —— 圆角、阴影、模糊、动画全部自己实现，不依赖系统组件
4. **混合生态** —— Android 应用为主力，Linux 沙盒作补充

## 技术栈

| 层 | 选型 |
| --- | --- |
| 语言 | C++20 |
| 图形（桌面开发） | OpenGL 3.3 Core · GLFW · libepoxy |
| 图形（Android） | OpenGL ES 3.x |
| 窗口接管 | TaskOrganizer / ShellTaskOrganizer（经 Shizuku） |
| 构建 | CMake + NDK |
| 目标平台 | Android 12+ |

渲染与交互逻辑先在桌面环境开发调试，再移植到 Android。shader 主体共用，仅版本行与 precision 不同。
